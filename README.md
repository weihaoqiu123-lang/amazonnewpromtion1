# amazonnewpromtion

AM 新品冲刺静态原型项目。

## 页面说明

- `index.html`：项目入口页
- `new-sprint-pool.html`：新品冲刺池列表
- `new-sprint-pool-remove.html`：移除冲刺池弹窗页
- `pricing-sprint.html`：冲刺中的货品定价详情
- `todo-list.html`：新品冲刺待办列表
- `pricing-finished.html`：已完结/移除后的货品定价详情
- `styles.css`：共享样式

## 使用方式

直接双击 `index.html` 即可本地预览。

若需上传到 GitHub：
1. 新建仓库 `amazonnewpromtion`
2. 将本目录全部文件上传到仓库根目录
3. 如需在线预览，可在仓库设置中开启 GitHub Pages

## 说明

该项目为静态原型，适合继续导入 Google AI Studio 或交给前端进行二次实现。
